# 全景图查看器 · Panorama Viewer

一个**单文件**的网页全景图查看器：把等距柱状（2:1）的全景图拖进浏览器就能看。

读取、投影、调色和导出**全部在你自己这台设备上完成** —— 图片不上传、页面不联网，断网也能用。

## 它能做什么

- **三种包裹样式**：球面（默认）/ 立方体 / 圆柱，一键切换，方便对照不同投影下同一张图长什么样
- **拖动环视**：鼠标拖、手指划，画面跟着手走（上下左右都是 1:1 跟手）
- **缩放跟着手指**：滚轮、双指捏合，都以光标 / 两指中点为轴，那一点不动
- **实时调色**：视野、曝光、对比度、饱和度、色温、暗角、锐度、水平校正（拖动即生效）
- **导出视角**：把当前看到的画面存成 PNG
- **三种喂图方式**：选择文件 / 拖进来 / 直接 `Ctrl` · `⌘` + `V` 粘贴
- **亮暗两套外观**：跟随系统，也可手动固定
- **展开图导航**：小地图上直接点、拖，跳到想看的方位

## 怎么用

1. 把这个仓库里的 `index.html` 下载下来（就这一个文件，没有别的依赖）
2. 双击打开，或者直接把它拖进浏览器窗口
3. 把全景图拖进去 —— 也可以点「**先看看示例**」看一眼效果

> 放个本地 HTTP 服务打开也行（`python3 -m http.server`），但**不是必须的**：直接双击文件就能用。

## 操作

| 想干什么 | 怎么做 |
|---|---|
| 环视四周 | 按住拖动（鼠标 / 手指） |
| 放大缩小 | 滚轮、双指捏合（跟着光标 / 手指的位置走） |
| 回到初始视角 | 双击画面，或按 `R`，或点工具栏的复位 |
| 换一张图 | 拖进来 / `Ctrl`·`⌘` + `V` / 工具栏「换一张」 |
| 全屏 | `F` |
| 小地图开关 | `M`（或面板里的「展开图导航」） |
| 上下左右微调 | 方向键；`+` `-` 缩放 |
| 自动旋转 | 面板里的「自动旋转」 |

## 已知的局限（如实写在前面）

- **只支持等距柱状 2:1 的图**。立方体贴图（六张面）不认，得先自己拼成等距柱状。
- **太大的图会被缩小**：超过显卡能吃下的尺寸（`MAX_TEXTURE_SIZE`，上限 8192）会先等比缩到能吃的尺寸，
  细节会有损失。手机上进大图尤其明显。
- **没有做畸变校正**：不是从全景相机出来的图（比如拼接的、或视场角不标准的），边缘会不自然。
- **立方体样式在棱上有折线**，这是该投影本身的样子，不是坏点。
- **导出用浏览器 canvas 实现**，分辨率极高时可能失败或很慢。
- **只在 Chrome / Edge 系的桌面上比较认真地试过**；老设备、低端手机可能卡；
  没有在多款浏览器和系统上完整跑过一遍。
- 示例图是**程序现画**的（不是照片），只用来演示三种投影的差别。

## 技术

- **一个 `.html` 文件**：CSS 和 JS 全部内联，没有构建步骤、没有包管理器、没有依赖
- 渲染用原生 **WebGL 1**——一个全屏三角形 + 一个片元着色器：
  由屏幕像素反推视线方向 → 映射到三种包裹面 → 采样等距柱状图 → 在着色器里做调色
- 交互与几何换算用原生 JS；界面用 CSS（含亮 / 暗两套变量、`prefers-reduced-motion` 降级）
- **不发起任何外部请求**：没有 CDN、没有字体外链、没有埋点、没有上传接口
  （图标是内联 SVG，字体只用系统已装的）
